    The six levels, in order

    Chemical, cellular, tissue, organ, organ system, organism. This is an introductory way to describe increasing structural complexity in human anatomy.

    Tissue is not the same as organ

    A tissue combines cells working in a related role. An organ contains multiple tissue types. The stomach, for example, includes more than muscle tissue alone.

    One organ can connect to several systems

    The six-level sequence is a useful map, not a set of sealed boxes. Organs can contribute to more than one system. This practice asks for the broad sequence rather than assigning every structure to one exclusive category.

    Practice it two ways
