    EVENING WORKSHEET

    Two plans for one finish time

    When your evening runs late, decide what still fits. Write a usual plan and a shorter version that ends at the same time.

    Download the one-page worksheet (PDF)
    Work through the exercise here

    Pick a finish time. In this example, both plans end at 22:30.

    • Usual plan: Pack a bag for 5 minutes, read for 15, then set an alarm for 2. That is 22 minutes. Begin at 22:08.
    • Shorter plan: Pack the bag for 5 minutes, read for 3, then take the same 2 minutes for the alarm. That is 10 minutes. Begin at 22:20.

    Write down up to four steps. Give each two durations, one for each version. Use zero for a step you decide to leave out. Add the minutes in each plan and subtract each total from your finish time. If your calculation crosses midnight, mark the previous day. Choose which version fits tonight.

    Use the planner to check each start time.

    Name the actual step.

    “Prepare tomorrow's bag” is easier to estimate than “get organized.” Keep the labels specific to your evening.

    Leave out the extras.

    Set a step to zero if you are not doing it tonight. This is a plan you can revise, not a list you have to complete.

    Build again when it changes.

    If a task takes longer than expected, edit the time and recalculate. The planner does not run a countdown or know your current progress.

    A plan, with clear limits.

    Does this tell me how much sleep I need?

    No. It only adds task durations and works backwards from the finish time you choose. It does not calculate sleep needs or treat sleep problems.

    Can the routine cross midnight?

    Yes. For example, a 40-minute routine finishing at 00:15 begins at 23:35 on the day before the target. Each step shows which day it belongs to.

    Will it remind me to start?

    It does not create alarms, notifications or a live timer. Copy or print the timetable to keep it. A timing-only link reopens the finish time and durations, with example step names.

    Are my routine details saved?

    This page does not automatically save or send your form entries. Copy or print your timetable before leaving. If you choose “Copy timing-only link,” the link includes your finish time and four durations, without step names. Opening that link requests its URL from the host.
