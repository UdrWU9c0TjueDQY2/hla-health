An evening review identifies one repeated problem: keys are left in different places. The owner wants to test a single practical change tomorrow, with a designated tray already available beside the usual departure route at home.

Show the worked answer

A. Use the tray as the chosen key location

The tray directly addresses the identified location problem and is already available on the departure route. A single focused change is easier to review against that problem than several unrelated changes introduced at once.
